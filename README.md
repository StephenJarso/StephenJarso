## Featured project

### [ApplyCanary](https://github.com/StephenJarso/applycanary)

[![Live demo](https://img.shields.io/badge/Live%20demo-Visit%20app-16a085?style=flat-square)](https://frontend-xi-seven-1v1qypqssw.vercel.app)

An agentic job-search assistant that:

- Finds and deduplicates roles from ATS boards and aggregators
- Scores opportunities against a candidate's real experience
- Tailors applications with a truth-checking gate
- Provides persistent, voice-enabled interview coaching
- Uses CockroachDB for transactional state and semantic memory
- Falls back gracefully to local inference, browser speech, and SQLite

**Built with:** Python · FastAPI · React · TypeScript · CockroachDB · AWS Bedrock · Polly · Transcribe · S3 · ECS/Fargate · Docker · Vercel
